# 知野教师工作台视觉重构设计

## 目标

将当前静态、规整的双卡片教师工作台重构为一个可承载大量教师功能、与欢迎页属于同一视觉世界的主工作台。

本轮重点是视觉与信息架构，不接入真实后端、AI、路由或数据接口。

## 已确认方向

采用 `A5 · 精炼自然光场`：

- 保留实用、稳定的多功能工作台结构。
- 桌面端侧边栏默认显示图标与中文功能名称。
- 中央区域突出当前最重要的课堂任务。
- 右侧展示今日队列与班级学习信号。
- 使用与欢迎页一致的自然、明亮、克制的视觉语言。
- 不直接绘制山、草地、河流、风筝等具象乡野图案。

## 页面结构

### 1. 功能侧边栏

桌面端宽度约 `176–200px`，默认展开，包含：

- 工作台
- 课堂
- 班级洞察
- 备课与测验
- 学生档案
- 任务
- 消息
- 设置

每项同时显示图标和中文名称。当前页面使用低饱和灰叶绿色背景高亮；课堂、任务和消息可显示数量徽标。

侧边栏品牌区提供有可访问名称的“返回知野首页”操作；底部显示教师身份和所教学科。提供折叠按钮；中等屏幕可以折叠为仅图标模式，但桌面默认不得使用无法识别的纯方块导航。

### 2. 顶部上下文栏

包含：

- 当前班级
- 学科与日期
- 全局搜索入口
- 网络/同步状态

使用接近实色的暖白表面和极轻阴影，不使用厚重玻璃效果。

### 3. 当前任务舞台

中央最大区域只突出一个当前最重要任务：确认“分数的基本性质”课堂复盘。

内容顺序：

1. 今日最重要
2. 课堂标题与说明
3. 录音 → 已转写 → 复习卡草稿 → 学生困难时间线
4. 学生复习卡草稿
5. 查看依据与“确认并发布”主操作
6. 最近课堂、备课建议和班级变化组成的低强调回流带

“确认并发布”是当前页面唯一强主操作。

### 4. 右侧行动区

右侧窄栏包含：

- 今日队列：课堂复盘、练习、家长消息和明日备课
- 班级脉搏：小型共性困难矩阵与文字摘要

右侧内容用于提醒和快速判断，不承载完整报告。

### 5. 知识点回响地图

之前的圆形“回响地图”不用于主页面布局，保留为班级洞察中的知识点下钻视图。

用户点击“单位换算 × 计算”等具体困难时，进入该视图查看：

- 课堂录音证据
- 复习卡关联内容
- 学生困难聚合
- 补讲建议

本轮只在主页面保留入口文案，不实现独立地图页面。

## 视觉语言

### 色彩

采用低饱和自然色，而不是鲜亮乡野插画色：

- 页面基底：暖灰白 `#F7F9F6`
- 雾蓝：约 `#D5E1E2`
- 灰叶绿：约 `#DCE8D5`
- 松影绿：约 `#526F59`
- 柔和麦金：约 `#C9A660`
- 主文字：墨绿黑 `#172019`
- 主操作：接近黑色 `#111511`

绿色只用于品牌、当前导航、学习状态和必要强调，不大面积铺满页面。

### 背景

背景使用：

- 低饱和、边界模糊的自然光场
- 右下角极淡地形等高线
- 当前任务区域内低透明度回响光环
- 很轻的底部明暗层次

明确禁止：

- 具象风筝、山坡、河流和云朵插画
- 高饱和蓝绿黄渐变
- 清晰可见的大色块圆形
- 重颗粒、厚玻璃和明显黑色阴影
- 为装饰而存在的持续漂浮动画

### 表面与阴影

- 侧边栏和顶部栏接近实色暖白，只保留少量透明度。
- 当前任务舞台使用暖白纸张感，而非玻璃卡片。
- 右侧卡片阴影低对比、带绿色调，不使用纯黑阴影。
- 卡片圆角保持统一：主舞台约 20px，内部内容约 14–16px，导航约 12px，按钮为胶囊形。

## 动效

- 背景不做持续位移动画。
- 导航、按钮和卡片只使用 `150–220ms` 的颜色、透明度和轻微位移反馈。
- 按钮按下缩放至约 `0.98`。
- 尊重 `prefers-reduced-motion`。

## 响应式

- `>= 1200px`：侧边栏完整显示图标和名称，右侧行动区可见。
- `768–1199px`：侧边栏折叠为图标模式，右侧行动区移动到主内容下方。
- `< 768px`：隐藏桌面侧栏，提供移动端顶部上下文与底部主导航；当前任务、队列和班级脉搏按单列排列。

## 实现范围

本轮修改：

- `src/components/WorkspaceScreen.tsx`
- `src/styles/theme.css`
- 必要时调整 `src/index.css`
- 更新 `WorkspaceScreen` 相关测试

本轮不修改：

- 欢迎页结构和背景图
- App 的欢迎页/工作台切换机制
- 后端、真实数据、登录、路由和 AI 服务
- 独立知识点回响地图页面

侧边栏功能、搜索、队列项和发布操作在本轮主要作为高保真交互原型；除返回首页、侧边栏折叠和必要的本地选中反馈外，不承诺真实业务行为。侧边栏使用 Lucide 图标并保留中文文本或可访问名称，折叠状态不得失去功能含义。

## 验收标准

- 桌面侧边栏中的每个功能都能通过图标和中文名称识别。
- 页面与欢迎页在色彩、文字和自然光感上具有连续性。
- 背景没有具象乡野插画或廉价的大色块渐变。
- 当前课堂复盘是页面唯一最强视觉和操作焦点。
- 大量功能可被发现，但不以等尺寸卡片网格铺满页面。
- 1440px、1024px 和 375px 宽度下无水平溢出。
- 所有主要按钮和导航目标至少 44px。
- 减少动态效果时页面仍完整可理解。
- 现有测试与生产构建通过。
