**打包前必须排除**（扫描一遍再压缩）：

```powershell
# 确认这些都不会进包
git status --short                 # 不应有 .env.local、录音原文件、node_modules、dist
Get-ChildItem -Recurse -Include .env*,*.webm,*.mp3,*.key -File | Select-Object FullName
```

- [ ] 无 `.env.local` / `DEEPSEEK_API_KEY`
- [ ] 无 `node_modules/`、`dist/`、`.pytest_cache/`

**生成校验清单**

```powershell
Get-ChildItem submission -File | ForEach-Object {
  "$( (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower() )  $($_.Name)"
} | Set-Content submission/checksums.txt
```

## 六、彩排问答（三个人最可能被追问）

| 问题 | 30 秒回答 |
|---|---|
| 为什么是智能体而不是问答工具？ | 它接管一条五步工作流：有目标、有计划、有工具状态、有失败重试，还有不可跳过的人工确认关卡。问答工具只替代一次搜索。 |
| 怎么保证模型不编？ | 三层：schema 强制每条推断引用课堂证据；prompt 只准依据给定上下文；教师确认才发布。任一层不过，内容到不了学生面前。 |
| 儿童数据安全？ | 音频题图不进云端、即用即删，密钥只在服务端；学生与家长可见内容必须教师确认；高风险表达走独立流程并留审计。当前是单机原型，正式上线需先接数据库与认证，这一点我们在文档里如实标注。 |
