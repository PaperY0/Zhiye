# 3、作品简介

知野是一款面向乡村小学教学场景的 AI 教育应用，以“课堂复盘数字员工”为核心，帮助教师把课堂记录转化为可审核、可使用的教学材料，并连接课前备课、课堂复盘、课后任务与学习反馈。

教师通过浏览器录制课堂音频，系统在本机完成语音转写，再结合课堂文本生成学生复习卡、教师课堂报告与课程进度建议。教师可以查看原始转写、核对课堂依据、编辑草稿并确认发布，未发布的课堂复习卡不会向学生开放。备课与任务模块支持生成教案、针对性练习和课堂热身，并将课堂内容衔接到课后任务。任务以“目标—证据—安排”组织，明确学习目标、可观察的完成标准和提交要求，帮助教师把教学建议落实为具体行动。

学生端提供课堂复习、任务提交、拍照答疑和错题整理。拍照答疑采用“题目识别与确认—选择卡点—分层提示—思路复述—变式练习”的学习路径，引导学生表达自己的尝试与理解。任务完成情况、测验结果和学生疑问可以在教师端查看，作为后续辅导与补讲的依据；家长端呈现孩子的任务进展与学习近况，管理端提供保护性反馈和审计流程的演示。

作品的特色是将课堂依据、AI 建议与教师决定区分呈现，把生成内容嵌入完整教学流程，同时重视儿童数据的最小必要使用。本地模式下，课堂音频与题图由本机模型处理，结构化生成仅向大模型提交所需文本，密钥保留在服务端。当前已形成包含教师、学生、家长和管理四端的单机 Web 原型，跨角色流程在同一浏览器内联动，适用于作品演示与功能评审。

# 4、创意来源

知野的创意源于对乡村小学“教师精力有限、学生课后支持不足、教学反馈难以连续利用”这一场景的关注。教师既要备课、上课和批改，也需要整理课堂重点、识别学生疑问并准备补讲材料；学生遇到困难时，需要适合当前理解程度的引导；家长则需要简明、可信的学习反馈。这些需求彼此关联，却容易分散在录音、作业、聊天记录和纸质笔记中。

因此，作品选择从课堂复盘这一具体环节切入：让课堂记录成为后续教学材料的依据，让 AI 承担转写、整理与草稿生成等重复工作，让教师负责核对、取舍与发布，再将学生的练习和提问反馈带回下一次教学安排。项目把语音识别、题图识别与大模型生成组合进教学流程，形成“课堂记录—教师审核—学生学习—反馈回流”的连续路径。

在设计中，知野坚持两项原则：一是帮助学生理解方法，通过分层提示、复述和变式练习支持学习；二是保留教师的专业判断权，通过可编辑草稿、课堂依据和明确的发布确认降低 AI 误判带来的影响。“知野”寓意“知其所学，野望生长”，希望用技术减轻教师的重复劳动，为孩子获得持续的学习支持创造条件。

# 5、运行环境

作品采用浏览器访问的 Web 应用形式，前端使用 React、TypeScript 与 Vite，本地 AI 服务使用 Python 与 FastAPI。

仅体验界面和内置演示数据时，可使用较新版本的 Chrome 或 Edge 浏览器，无需配置大模型密钥。本地运行前端需安装 Node.js 20.19+ 或 22.12+、pnpm 10.28.0，默认访问地址为 http://127.0.0.1:8443。

体验真实录音转写、题图识别及 AI 生成时，建议使用 Windows 10/11 电脑，另需安装 Python 3.11–3.12（题图 OCR 推荐 3.12）、FFmpeg 及项目所列依赖，配置可用的 DeepSeek API Key，并启动本地 AI 服务，默认端口为 8787。首次运行需要联网下载 FunASR、PaddleOCR 等模型，并预留数 GB 磁盘空间；大模型生成需要联网。课堂录音需可用麦克风及浏览器授权，语音转写默认使用 CPU。

当前版本采用浏览器本地存储，数据在同一浏览器及同源标签页之间同步；不依赖数据库即可演示，跨设备数据共享与正式账号认证尚未接入。
