# 知野本地 AI 内容生成接入设计

日期：2026-08-09  
状态：已获用户确认，待实现

## 目标

将当前原型中标注为 AI 生成、但由固定 fixture 或确定性模板提供的内容，接入受控的本地 AI 服务。浏览器只访问 `127.0.0.1:8787`；该服务在本机完成音频转写、题图 OCR，并使用服务器环境变量中的 DeepSeek 密钥完成文本生成。

## 范围

本次接通以下教师与学生主线：

- 课堂录音：FunASR 转写后生成学生复习卡、知识点、下一步建议、教师课堂报告草稿。
- 教师备课：从教师填写的教学上下文和主动选择的证据生成可编辑教案草稿。
- 教师测验：从教师指定的主题、难度和关注点生成三题可编辑测验草稿。
- 班级洞察：把教师主动选择的班级信号转换为补讲草稿。
- 学生知识点学习：用已发布复习卡和当前学生问题生成解释、例子、知识卡与追问。
- 拍题答疑：本机 PaddleOCR 识别题图文字；学生确认文字后，DeepSeek 生成分层提示、完整讲解、复述追问与迁移题。
- 家长陪伴摘要与学生 AI 推断：仅根据原型中已有学习事实生成待审核草稿。

以下内容不进入模型自动决策：保护性反馈定性、审计日志、发布动作、普通消息发送、学生排名或人格标签。

## 架构

```text
React 原型
  | 受控 HTTP 请求（无密钥）
  v
本地 AI 服务 :8787
  |- /analyze      音频 -> FunASR -> DeepSeek 课堂复盘 JSON
  |- /generate     结构化上下文 -> DeepSeek 内容草稿 JSON
  |- /solve-image  图片 -> PaddleOCR -> 学生确认文本 -> DeepSeek 分层答疑 JSON
  v
DeepSeek Chat Completions
```

服务端按任务类型使用独立 prompt 和 JSON schema。每项响应均验证必填字段、字符串长度、题目数量和选项/答案一致性；验证失败返回明确错误，不制造本地成功结果。

## 接口契约

### `POST /generate`

请求字段：`kind`、`context`。`kind` 只允许 `lesson-plan`、`quiz`、`remedial-plan`、`learning-reply`、`retell-follow-up`、`parent-summary`、`student-inference`。

响应字段随 `kind` 变化，但始终包含 `draft: true`、`source: "deepseek"` 和结构化内容。前端不信任任意字段；只接受对应任务的已验证结构。

### `POST /solve-image`

请求为图片文件，返回 `recognizedText`、`ocrConfidence` 与 `needsConfirmation`。当 OCR 为空、置信度不足或题目不完整时只返回补拍提示，不调用 DeepSeek。

学生确认题目文字后，前端以确认文本和选择的卡点调用 `/generate` 的 `learning-reply`/`retell-follow-up` 任务，服务端返回对应提示层级内容。

### `POST /analyze`

保留既有音频上传语义，并扩展为返回 `recap`、`recapTags`、`nextStep`、`teacherReport`、`progressSuggestion` 与 `evidence`。所有输出是教师可编辑草稿，默认不发布。

## 用户体验与状态

- 请求中显示“正在识别”或“正在生成”，不显示虚假百分比。
- 服务不可用、超时、模型响应无效、OCR 不清晰分别显示可行动错误与“重试”入口。
- 没有成功响应时，当前固定示例不再伪装为新生成内容。
- 所有模型结果显示“AI 草稿”，学生与家长可见内容仍遵循教师确认发布规则。
- 当前 Vite 原型只在页面状态中保存生成结果；不声称已写入生产数据库。

## 隐私与安全

- `DEEPSEEK_API_KEY` 仅从本地服务进程环境变量读取，绝不传入前端、fixture 或日志。
- 题图由 PaddleOCR 在本机处理；传给 DeepSeek 的仅是学生确认的题目文本、卡点和最小学习上下文。
- 课堂音频只在本地临时文件中处理，完成后删除。
- 生成提示禁止模型诊断学生、推断人格或编造未提供的课堂事实。

## 验收

1. 本地服务健康检查通过，且在服务停止时前端明确提示不可用。
2. 录制一段有效音频后，课堂转写与复盘草稿来自 `/analyze`，并能由教师编辑、确认发布。
3. 以相同输入连续生成两次教案或测验，结果可不同，且均通过结构校验。
4. 上传清晰数学题图后，先展示 OCR 文本确认；确认后按所选卡点得到非固定的分层答疑内容。
5. 上传无法识别图片时，不出现虚构题目或答案。
6. 学生追问、复述追问、补讲、家长摘要和学生推断均标为 AI 草稿，并在失败时能重试。
7. 现有测试与生产构建通过。
