# 知野 · 演示视频稿

> 配套：[比赛演示课堂讲稿](classroom-script.md)｜[项目文档](../submission/zhiye-project-doc.html)
> 用途：2026年iCAN大学生创新创业大赛 AI应用创新挑战赛 作品演示视频
> 时长：**5 分钟标准版**（另附 3 分钟精简版裁剪点）

## 一、拍摄前检查清单

### 环境（按顺序做，别在录制中才发现）

```powershell
# 1) 启动两个服务
.\scripts\start-dev.ps1            # 前端 8443 + 本地 AI 8787，并自动打开教师端

# 2) 确认 AI 就绪（返回 deepseek:true 才能录"真机"流程）
curl.exe --noproxy '*' http://127.0.0.1:8787/health

# 3) 打开演示入口，确认默认脱敏数据在位
#    http://127.0.0.1:8443/#/teacher/workspace
```

- [ ] `/health` 返回 `"deepseek":true`（若为 `false`，见第四节应急预案 B）
- [ ] 浏览器窗口 **1440×900**，书签栏/扩展图标隐藏，地址栏可用（要展示 `127.0.0.1:8443`）
- [ ] 麦克风可用（录音环节要用），系统通知与输入法候选框关掉
- [ ] 提前读一遍"课堂录音稿"（第二节），控制在 90 秒内读完
- [ ] 先在演示前点一次"重置演示数据"（教师端 → 设置），保证每条都从同一状态开始
- [ ] 录屏软件设为 1920×1080 或 1440×900，30fps，同时录系统音
- [ ] 桌上放一杯水；全程用耳机监听，避免外放回环

### 人员与节奏

- 一个人可以完成：左手操作、右手持稿、旁白先行。
- 每说完一句话再点鼠标，**操作永远比旁白慢半拍**，不要抢话。
- 卡住超过 3 秒就切下一句，不要重复念。

## 三、五句必须说到的关键信息

按顺序核对，漏一句就补拍：

1. 「它不是聊天机器人，它接管的是录音—转写—证据—复盘—审核—发布的完整工作流。」
2. 「音频在本机转写，题图在本机识别，只有文本交给大模型。」
3. 「每条建议都能回到课堂原话；模型推断和课堂事实分开显示。」
4. 「教师确认是唯一的发布门槛，学生和家长看不到未经确认的内容。」
5. 「失败会说清楚哪一步坏了，可以只重试那一步，已成功的步骤不会重跑。」

## 四、应急预案

### A. 本地 AI 转写/生成慢或卡住
- 不要干等。旁白接着说「这一步在本机跑，首次要加载模型」，同时用另一台设备或提前准备好的录屏片段接上；正片允许剪切。
- 若超过 90 秒无响应，直接走 B 方案。

### B. 没有可用的 DeepSeek Key（`/health` 返回 `deepseek:false`）
改用**演示数据路径**，一样能讲完主线：
1. 直接打开教师端「工作台」——默认数据里已有一节"分数的基本性质"处于 **AI 初稿** 状态。
2. 点「查看并发布」→ 课堂详情 → 逐 tab 讲转写、复习卡、报告、进度。
3. 改一句复习卡 → 「确认并发布」→ 切学生端看复习卡。
4. 继续第三、四节的学生端与回流。
5. 旁白把「我先录一段」改成「这是一节已经跑完的课堂，我们直接看结果」。
> 注意：此时**不要**声称"刚才是我现场录的音"。

### C. 录音失败（无麦克风权限 / 空音频）
- 这本身是可演示点：指着错误提示说「它没有伪装成功，而是告诉我是麦克风权限问题，并给我重试入口」——正好证明第四节的设计。

### D. 时间不够（只给 3 分钟）
裁剪点（保留骨架，砍细节）：
- 删 0:18–0:50 痛点段，把时间账并进开场一句。
- 课堂朗读压缩到 20 秒（提前剪好）。
- 1:20–2:40 只保留：五步流程一句 + 两条证据 + 报告一句。
- 删「根据课堂生成三题任务」和家长端。
- 保留：教师确认发布、学生端只看已发布、拍照答疑先提示后讲解、班级洞察回流、收尾金句。

## 七、评委可能追问的三句话（备好，不要现场想）

| 问题 | 回答 |
|---|---|
| 为什么必须是智能体，不能就是个问答工具？ | 因为它要接管一条五步工作流，有目标、有计划、有工具状态、有失败重试，还有不可跳过的人工确认关卡。问答工具只替代一次搜索。 |
| 怎么保证模型不编？ | 三层：schema 强制每条推断引用课堂证据；prompt 只准依据给定上下文；教师确认才发布。任一层不过，内容就到不了学生面前。 |
| 数据安全怎么办？ | 音频和题图不进云端、即用即删，密钥只在服务端；学生与家长可见内容必须教师确认；高风险表达走独立流程并留审计。 |
