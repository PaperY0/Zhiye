# Day 06 补充 · 确认发布状态修复

## 根因

“确认发布给学生”原先只设置了审核组件内部的 `confirmedAt`，没有更新五步工作流中的 `teacher-review` 步骤，也没有把发布后的复盘任务写回共享状态。因此页面仍显示第 5 步待审核，刷新后也会回退。

## 修复

- 发布时原子更新课堂复习卡和 `studentVisibility`。
- 发布时同步更新 `teacher-review` 为 `succeeded`，摘要为“已完成发布”。
- 顶部状态改为“已发布”，工作流改为 `5/5 已完成`。
- 发布按钮变为禁用的“已发布”，避免重复提交。
- 发布后的 RecapJob 写回 PrototypeContext，刷新页面仍保持已发布状态。
- 学生首页不再把隐藏的草稿当作今日复习卡展示。

## 验收

浏览器实际验证：点击确认发布后立即显示：

- 顶部“已发布”；
- “5/5 已完成”；
- 第 5 步“已完成发布”；
- 审核卡状态“已发布”；
- 按钮变为禁用“已发布”。

刷新页面后以上状态仍保持。
