# 知野桌面端交付清单

## 运行与构建

- 开发预览：`npm.cmd run dev`
- 地址：`http://localhost:8443/`
- 自动化测试：`npm.cmd run test -- --run`
- 生产构建：`npm.cmd run build`

## 已完成的桌面端闭环

- 欢迎页进入教师、学生、家长和管理端。
- 教师工作台展示课堂复盘、处理进度和今日行动队列。
- 课堂页支持状态筛选、新建课堂录音和课堂详情入口。
- 课堂详情支持复习卡确认、课程进度保存和发布二次确认。
- 学生档案区分可核实事实与 AI 辅助线索，教师笔记可保存。
- 教师设置支持保存、刷新保留和演示数据重置确认。
- 学生任务支持开始、提交和状态反馈。
- 家长与学生首页显示最近学习记录。
- 管理端支持保护性反馈、审计记录和学校设置。

## 桌面端验收标准

- [ ] 1440×900 下工作台首屏不产生页面滚动，核心复盘卡和右侧行动区可见。
- [ ] 教师主侧栏在工作台、课堂、学生档案和设置页保持 `232px`。
- [ ] 主路由切换后页面标题、导航高亮和内容区域同步更新。
- [ ] 保存、发布、任务开始/提交、重置等操作均有明确反馈或确认。
- [ ] 保护性反馈和审计页面不展示完整敏感正文。
- [ ] 浏览器控制台无错误，页面无横向溢出。
