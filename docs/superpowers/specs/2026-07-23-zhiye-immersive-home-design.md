# 知野沉浸式欢迎页改造设计

## 目标

将当前单屏教师工作台演示改为可运行的两段式体验：先进入充满生命力的欢迎页，再由用户主动进入课堂回响工作台。欢迎页应呈现“自由、蓬勃、有生机”的知野世界，而非通用 SaaS 或液态玻璃展示页。

## 采用方向

采用“野境回响”方向：自然视频作为环境底层，深青绿与日光黄绿建立空间深度，课堂声音与知识轨迹作为少量动态信号。视觉节奏参考附件的全屏视频 Hero 与精确排版，但不复制其 LinkFlow 文案、导航、配色或营销结构。

## 体验流程

1. 初始加载显示 `Welcome`：全屏视频环境、品牌名、主叙事“让一节课在放学后继续生长”、唯一主操作“进入今天的课堂”。
2. 视频加载前显示渐变与细微声波骨架；视频失败时维持可用的静态自然渐变，不留下黑屏。
3. 点击主操作后，欢迎页的标题、声波与视频遮罩向内收束，500ms 内切换至 `Workspace`；用户可用“返回知野”回到欢迎页。
4. `Workspace` 保留课堂回响、复习卡、班级洞察和发布动作，但移除调试态切换按钮；把首屏改为真正可操作的课堂复盘入口。

## 页面结构

### WelcomeScreen

- 顶部：知野文字标识、三个低干扰锚点（知野做什么 / 课堂回响 / 登录）。移动端使用可访问的展开菜单。
- 中部：大字号中文叙事；一句解释“声音、笔迹与孩子的思考，回到下一节课堂”；主操作及一个“观看 36 秒课堂回响”的次操作。
- 环境层：附件提供的视频以原生静音循环播放；其上仅有一个颗粒遮罩、一个从声音扩散的知识轨迹和三处低频光点。
- 底部：真实状态信息，例如“正在整理今天 3 节课的课堂回响”，避免营销式功能罗列。

### WorkspaceScreen

- 用语义化顶部导航替代仅靠 hover 才可理解的图标轨道。
- 主编辑区包含可编辑的复习卡、依据入口和真实处理/离线状态。
- “班级脉搏”改为可展开的证据面板；发布完成后才突出下一课补讲建议。

## 动效规则

- 环境视频和背景轨迹为慢速、低频运动；不对每张卡片施加悬浮或循环动画。
- 进入工作台使用共享元素：欢迎页的“课堂回响”光点收束到工作台中的录音节点。
- 交互反馈 150–250ms；页面进入/收束 420–560ms；尊重 `prefers-reduced-motion` 并退化为淡入淡出。
- 所有关键动作可中断，且不依赖动画才可理解状态。

## 技术方案

- 保持现有 Vite、React 19、TypeScript、Tailwind CSS 4 与 Lucide，不降级到附件所列 React 18/Tailwind 3。
- 新增 `src/components/WelcomeScreen.tsx`、`src/components/VideoBackdrop.tsx`、`src/components/WorkspaceScreen.tsx`；`App.tsx` 只管理当前体验阶段。
- 视频使用附件的 CloudFront 地址。先使用 `video` 原生循环与 poster/fallback，避免把整段视频逐帧存入 Canvas 造成的内存风险；若后续确需往返播放，再在视频时长和最大帧数受控的条件下引入 Boomerang 版本。
- 将颜色、时长、缓动与表面层级写为 CSS 变量，避免 JSX 内散落色值。

## 验收标准

- 首屏在 375px、1024px 与 1440px 均完整可见，无横向裁切。
- 视频不可用时，标题、导航、CTA 和进入工作台仍完整可用。
- 页面存在欢迎页与工作台两种可达状态，且能够往返。
- 无调试状态切换控件、无 LinkFlow 文案、无复制附件的品牌内容。
- 键盘可以访问导航和主操作；图标按钮有可读名称；减少动态效果时不出现持续位移动画。
- 安装依赖后 `npm.cmd run build` 可通过。

## 不在本轮范围

- 后端认证、真实音频上传、AI 服务、班级数据接口。
- 将视频逐帧缓存为 Canvas 的往返播放实现。
