# 知野本地原型验收清单

## 运行方式

- 启动：`npm.cmd run dev`
- 地址：`http://localhost:8443/`
- 自动化回归：`npm.cmd run test -- --run`
- 生产构建：`npm.cmd run build`

## 路由与壳层

- [ ] 欢迎页 `/welcome` 能进入教师、学生、家长、管理四种角色。
- [ ] 23 个角色路由均显示对应角色的主导航。
- [ ] 当前路由在桌面侧栏和移动导航中都有正确高亮。
- [ ] 工作台与其他教师页面使用相同侧栏宽度和品牌区域。
- [ ] 刷新当前 hash 后仍停留在当前页面。
- [ ] 浏览器后退/前进能恢复上一页和下一页。
- [ ] 未知 hash 安全回到欢迎页。

## 教师闭环

- [ ] 工作台 → 课堂详情 → 复习卡确认/发布 → 学生视图。
- [ ] 工作台行动队列中的课堂、家长消息、班级脉搏都能跳转。
- [ ] 课堂页可筛选状态，录音流程能展示待开始、处理中、待确认、已发布。
- [ ] 备课、测验、任务可以创建草稿并发布。
- [ ] 学生档案区分学习事实和 AI 推断。

## 学生闭环

- [ ] 学生首页只显示教师已发布内容。
- [ ] 拍照答疑按卡点进入分层提示。
- [ ] 学生完成复述和迁移题后可以保存错题。
- [ ] 错题本支持筛选、查看详情和模拟复习提醒。
- [ ] 学生消息不显示家长会话，也不允许陌生人私信。

## 家长与保护

- [ ] 家长只能看到绑定孩子的陪伴摘要和教师留言。
- [ ] 家长页面明确不播放、不上传真实音频。
- [ ] 学生“想说一说”能区分普通反馈与需要帮助的反馈。
- [ ] 保护性反馈能分配、转交、跟进和关闭。
- [ ] 保护流程产生审计事件且不展示敏感正文。

## 响应式与无障碍

- [ ] 1440px 桌面：左栏、主内容、右侧行动区不溢出。
- [ ] 1024px 平板：导航仍可用，右侧行动区收敛。
- [ ] 390px 手机：底部导航不遮挡主要按钮，内容可滚动。
- [ ] 所有主操作有可访问名称和键盘焦点。
- [ ] 开启减少动效和减少透明度时仍能完成流程。
