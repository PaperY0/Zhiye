# Day 06 补充 · 教师端共享发布链路修正

## 根因

首页的“确认并发布”、课堂详情页和“课堂复盘数字员工”分别进入三套发布交互；复盘页还使用独立 demo job，发布时没有稳定绑定 `lesson-fractions`，因此学生端读取不到教师刚刚编辑的内容。

## 修正

- 首页主操作改为进入唯一的“课堂复盘数字员工”审核页。
- 课堂详情页不再保留第二套发布弹窗，完整分析时统一跳转到复盘审核页。
- 复盘页直接读取共享课堂 `lesson-fractions` 的复习卡、教师报告、补讲建议和课堂证据。
- 发布时写回同一份 PrototypeContext 课堂状态；学生首页和学生复习页读取同一状态。

## 实际浏览器验收

1. 教师首页点击“进入复盘审核”，路由为 `#/teacher/recap-agent`。
2. 在数字员工页把学生复习卡改为“统一链路验收复习卡：分子和分母要同时乘同一个不为零的数。”。
3. 完成“确认发布给学生”。
4. 切换学生端，打开“分数的基本性质复习卡”。
5. 学生端实际显示上述修改后的文本。

## 回归结果

- Production build 通过；仅有既有主 bundle 体积警告。
