# 知野 Figma Make V2：iPadOS 教研编辑台首屏提示词

> 先用本提示词只生成一个教师端主页面。确认视觉方向后，再扩展其他页面；不要与旧版全量提示词同时粘贴。

```text
重新设计「知野」的教师端首页。不要沿用普通 SaaS 后台的“三栏导航 + 大标题 + 白色任务卡”布局。请把它设计成一张具有 iPadOS 创作工作台气质的高保真桌面界面：安静、沉浸、温暖、空间连续，有真实任务流，而不是常规仪表盘。

产品：知野，面向乡村小学教师的课堂复盘与精准补讲 AI 助手。它的核心不是展示待办事项，而是让教师清楚看见一节课从“录音”到“复习卡”再到“学生真实困难”的连续回响。

画板尺寸：1440 × 1024，桌面端。

【绝对不要】
- 不要大标题“今天，先完成这一节课堂复盘”。
- 不要传统固定三栏后台；不要右侧塞几张小白卡。
- 不要出现 Teacher/Desktop、Student/Mobile、Guardian/Mobile 的原型切换标签。
- 不要做成绿色圆角卡片的堆砌、企业 CRM、数据大屏、乡村宣传海报或幼儿园卡通界面。
- 不要复制 Apple Logo、iOS 设置页、macOS 菜单栏或具体系统图标。

【设计隐喻】
这是一个“课堂回响编辑台”：教师像在一张干净、温暖的数字工作台上整理刚刚结束的一节课。声音、知识、学生困惑和下一步补讲以连续的材料层自然排列，而不是互不相关的组件。

【视觉方向：iPadOS 创作工作台】
- 页面外层使用深石墨灰/近黑色工作区背景 #151917，让中央工作台像一张悬浮在深色空间里的暖白画布，而不是整屏白色网页。
- 主工作台为暖象牙白 #F5F3EC，圆角 30px，在四周留出至少 36px 深色呼吸边缘。工作台有极轻微阴影和内侧高光，像一层真实材质。
- 用低对比度松绿 #245A43 作为唯一强主色；麦穗金 #C79035 只用于进度、完成、音频时间点等小范围重点。
- 文字为深墨绿黑 #17211C；次文字为 #6D756F。不要大面积纯黑。
- 使用 SF Pro Display + PingFang SC；标题和数字具有苹果式精确字距与充足行高。
- 导航、过滤器、临时工具应是轻质磨砂玻璃层：半透明白、模糊背景、细亮边；内容卡是较实的纸张层。不要把玻璃叠在玻璃上。
- 整个页面最多 3 种表面层次：工作台底纸、悬浮编辑纸、玻璃工具层。
- 无大面积插画。只允许使用抽象声波、轻微纸张纹理、知识节点/连线作为信息可视化材料。

【空间结构】

1. 深色工作区背景上，中央是一张 1368px 宽的暖白“教研工作台”。

2. 工作台顶部不要传统 Header。做一个距顶部 22px、居中悬浮的玻璃工具条，高约 56px，圆角 18px：
   - 左侧小型文字 Logo：“知野”。不要夸张大 Logo。
   - 中间：胶囊式班级切换“五年级（2）班”、分隔符、学科“数学”、下拉箭头。
   - 右侧：日期“7 月 21 日 · 周二”、通知图标、教师头像“李”。
   - 工具条应该像可以浮在工作台上的上下文控制器，不占用一整条硬导航。

3. 左侧不是厚重侧栏。设计一条半透明、可收缩的垂直“工具轨道”，距画布左侧 24px、距顶部玻璃条下方 32px，宽度约 72px：
   - 图标：首页、课堂、洞察、备课、消息。
   - 当前“首页”以柔和松绿光晕/浅松绿圆角方块强调。
   - Hover 时在右侧出现短文字标签；默认不要把大量文字塞进导航。
   - 底部有一个低调设置图标。

4. 主内容从左侧工具轨道右边开始，采用不对称的“创作画布 + 脉搏浮层”结构，而不是规则三栏。

【核心主视觉：课堂回响画布】

在中央偏左放置一个大而有呼吸感的“课堂回响”编辑纸，约 760px 宽、560px 高、圆角 28px、实色暖白表面，轻微阴影。它是全页唯一最强焦点。

编辑纸内容必须按一条连续时间线组织：

- 顶部小标签：今天 10:30 完成的数学课。
- 标题：分数的基本性质。标题大小约 32px，不超过两行。
- 副标题：40 分钟课堂录音已经整理成一张学生能看懂的复习卡。
- 中部是一条漂亮、克制的“课堂回响轨道”，横向从左到右自然连接：
  课堂录音（小麦穗金时间点 + 极简声波） → 已转写（文本片段） → 复习卡草稿（当前高亮） → 学生课后困难（淡色节点）。
- 声波不是装饰：在轨道左段有 3 个可点击的时间点标签“05:12 分数不变”“18:40 约分”“31:26 单位换算”，其中“单位换算”用很轻的麦穗金强调，表现它是之后学生最常卡住的地方。
- 轨道下方嵌一张“复习卡草稿”纸片，像从编辑纸里自然浮出来。内容简洁但真实：
  - 小标题：给学生的复习卡
  - 一句话：分子和分母同时乘或除以相同的数，分数的大小不变。
  - 两个知识标签：约分、分数基本性质。
  - 一个自检问题：为什么 1/2 和 2/4 一样大？
- 编辑纸底部左侧有柔和小字：“32 名学生将在发布后看到这张复习卡。”
- 编辑纸底部右侧只有一个强操作：深松绿按钮“确认并发布”。旁边不要放巨大的次按钮；将“稍后处理”做成低调文字操作。

【班级脉搏浮层】

在主编辑纸右上方以叠放/错位关系放一个约 390px 宽的“班级脉搏”浮层。它不是僵硬右栏，而是贴近课堂回响画布的第二层材料；与主卡有 24px 叠压或轻微错位，形成深度。

- 浮层标题：班级脉搏；副标题：学生课后正在告诉你什么。
- 主内容做一个小而精致的知识点热力图，不做传统红绿矩阵：
  - 横轴：读题、列式、计算、检验。
  - 纵轴：约分、通分、单位换算。
  - 使用松绿的透明度变化与一个麦穗金点；不要使用鲜红。
  - 高亮“单位换算 × 计算”：12 位学生在这里停下来。
- 热力图下方是一张可执行的建议条：
  “下一节课，用 5 分钟把单位换算再讲一遍。”
  文字按钮“生成补讲方案 →”。
- 右上有很小的动态状态点：“刚刚更新”。

【底部回流带】

在工作台底部设计一条横向、低强调的“学习回流带”，不要变成一排平铺卡片：
- 标题：课后回响。
- 以三段连续小材料呈现：
  1. 学生小乐：完成复习卡（绿色细勾）。
  2. 7 位学生：在“单位换算”请求了提示（麦穗金细点）。
  3. 建议：把这类题加入明天的 5 分钟热身（深松绿文字链接）。
- 用细线或柔和路径把三个片段接起来，表现数据从学生端回到老师端。

【背景与留白】
- 工作台不能有巨大空白下半屏。主编辑纸、班级脉搏浮层、底部回流带应构成紧凑但不拥挤的视觉三角。
- 暖白画布上可在极远背景有非常轻的点阵/知识连线纹理，透明度低于 4%，几乎不可见。
- 深色外部工作区不放内容，只用来衬托悬浮工作台与层级。

【需要生成的交互状态画板】

除主画板 `Teacher Dashboard / Classroom Echo` 外，再生成同一页面的 4 个状态变体，保持布局一致：

1. `Teacher Dashboard / Processing`：
   - 课堂回响轨道当前停在“正在整理复习卡”。
   - 显示真实阶段标签，不显示假百分比进度条。
   - 班级脉搏保持可查看，但主按钮变为“正在整理…”。

2. `Teacher Dashboard / Published`：
   - 复习卡纸片从“草稿”变为“已发送给 32 名学生”。
   - 时间线的学生课后困难节点轻微点亮。
   - 主操作变为“查看学生视图”，出现克制成功 Toast“复习卡已发布”。

3. `Teacher Dashboard / No pending lesson`：
   - 主编辑纸变为更大的班级学习地图。
   - 标题“下一节课，可以先讲这两件事”。
   - 热力图扩大，底部保留“生成补讲方案”主操作。

4. `Teacher Dashboard / Offline`：
   - 顶部玻璃工具条下有一条很窄的低干扰状态条：“网络不稳定，课堂内容已保存在本机，将在联网后同步。”
   - 不能遮挡主任务，也不要使用危险色。

【组件和实现要求】
- 使用 Auto Layout。
- 创建并复用：GlassToolbar、ToolRailItem、ClassroomEchoCanvas、LessonEchoTrack、RecapDraftSheet、ClassPulsePanel、InsightHeatmap、ActionSuggestion、FeedbackLoopStrip、StatusChip、PrimaryButton、Toast。
- 使用变量：Color、Space、Radius、Typography、Effect；不要用大量单独硬编码色块。
- 所有文本使用真实中文，不要使用 Lorem Ipsum、Title、Subtitle、Button 等占位文本。
- 最小可点击尺寸 44 × 44px；主按钮高度 48px。
- 所有状态除颜色外必须有文字和图标/形状差异。
- 给关键组件添加简短设计注释：例如“处理状态应使用真实阶段”“该热力图展示共性困难，不展示学生排名”。

【原型连接】
- 点击“确认并发布”：从主状态 → Published 状态；复习卡纸片自然收束为已发送状态，班级脉搏中的单位换算节点点亮。
- 点击“生成补讲方案 →”：打开一个从班级脉搏浮层右下方展开的轻量编辑纸/Bottom Sheet，而不是跳转到空白页面。
- 点击“课堂录音”的时间点：在主编辑纸内展开一个小的转写片段 Popover，锚定在该时间点。
- 鼠标悬停工具轨道图标：显示短标签；不要让导航常驻占大宽度。

【生成完成后自检】
1. 它是否一眼看起来像“课堂回响编辑台”，而不是普通教师后台？
2. 是否有明确空间层次：深色工作区、暖白工作台、纸张编辑层、玻璃工具层？
3. 是否把“录音 → 转写 → 复习卡 → 学生困难 → 补讲”作为一条连续视觉叙事？
4. 主按钮是否只有“确认并发布”一个，且不被多余按钮分散？
5. 班级脉搏是否真正可视化了共性困难，而不是右栏小文字卡？
6. 是否避免了传统三栏仪表盘、厚重卡片、巨大标题和大面积空白？
7. 是否具有 iPadOS 创作工具的轻盈与材质层次，但没有复制 Apple 的具体 UI？
8. 所有中文是否清晰、未截断、对比度足够？
```

## 使用方式

1. 将上方代码块单独粘贴到 Figma Make，先生成这一个教师桌面页及其状态变体。
2. 不要同时粘贴旧版全量提示词；旧版用于定义系统全貌，V2 用于先把视觉方向做对。
3. 生成后截取 `Teacher Dashboard / Classroom Echo` 发给我；我会针对空间层级、材质、构图和连贯动效继续做第二轮精修。
