# 知野首轮试点权限矩阵与越权拒绝测试

状态：首轮领域权限拒绝规则与 HttpOnly Cookie policy 已实现；`apps/web` 已建立 Auth.js route handler、登录/退出和本地演示 Provider，并已用 PostgreSQL 脱敏种子用户完成邮箱查询；真实学校账号 Provider、正式 Adapter 和 API 数据查询仍待完成

## 1. 先明确边界

当前 Vite 原型中的“切换体验角色”只用于演示不同页面，不是认证，也不是权限控制。真实试点必须在服务端完成身份、学校、班级、绑定关系和保护职责校验；前端隐藏按钮不能作为安全边界。

角色简称：

- `teacher`：任课教师，只能访问被分配班级和学生。
- `student`：学生，只能访问自己的学习数据和所属班级已发布内容。
- `guardian`：已绑定监护人，只能访问绑定孩子的审核后摘要与教师沟通。
- `admin`：学校管理员，可管理学校配置和必要运营元数据，但不因管理员身份默认读取学生私密内容。
- `safeguarding_lead`：保护负责人，可处理被分配的保护案件和必要审计元数据，不读取无关普通对话。

## 3. 必须拒绝的场景

每个场景都必须返回稳定的拒绝结果，例如 `403 FORBIDDEN`、`404 NOT_FOUND`（避免泄露对象存在性）或 `409 CONFLICT`；不能只在前端隐藏入口。

1. 学生请求另一名学生的复习卡、错题、答疑或消息。
2. 未绑定监护人请求某个学生的家长摘要。
3. 监护人请求完整课堂转写、题图、完整学生对话或保护正文。
4. 教师请求不属于自己学校或不属于自己班级的学生档案。
5. 教师请求保护案件完整正文，且本人不是被授权的保护负责人。
6. 管理员通过普通管理接口读取学生私密正文或保护正文。
7. 任意角色尝试直接修改或删除审计事件。
8. 任意角色尝试将课堂草稿直接标记为学生可见，绕过教师确认。
9. 任意角色修改另一个主体的任务提交、错题掌握度或教师笔记。
10. 通过修改 URL、对象 ID、表单隐藏字段或重放请求绕过上述限制。

## 4. 越权拒绝测试清单

### 身份与组织

- [x] 未登录访问任一私有接口返回拒绝，不返回业务数据。
- [ ] 教师 A 访问教师 B 的班级返回拒绝。
- [ ] 学校 A 的管理员访问学校 B 的对象返回拒绝。
- [ ] 退出后旧会话、旧链接和浏览器后退不能恢复业务数据。

### 学生与监护关系

- [ ] 学生只能读取自己的 `studentId`。
- [ ] 学生不能通过修改 URL 读取另一学生详情。
- [x] 未绑定监护人不能读取摘要；解除绑定后旧链接立即失效。
- [ ] 绑定监护人不能读取完整对话、题图、排名或保护正文。

### 教师与发布状态

- [x] 教师只能读取被分配班级的课堂和学生。
- [ ] 草稿、低置信度建议和教师报告对学生不可读。
- [ ] 发布必须经过确认；重复发布具有幂等性，不产生重复学生内容。
- [ ] 学生端只返回 `PUBLISHED` 内容，不接受前端传入的可见性绕过字段。

### 保护与审计

- [ ] 普通消息接口不能读写保护反馈正文。
- [x] 只有被分配的保护负责人可以推进案件状态。
- [ ] 分配、转交、跟进、关闭都产生审计事件。
- [ ] 审计事件追加写入，不提供业务删除和普通修改接口。

## 5. 生产实现入口

权限检查必须位于服务端领域层/API 入口，而不是页面组件中。首轮生产实现至少提供：

```text
getSessionUser()
requireRole(role)
canAccessSchool(userId, schoolId)
canAccessClassroom(userId, classId)
canReadStudent(userId, studentId)
canReadParentSummary(userId, summaryId)
canAccessSafeguardingCase(userId, caseId)
```

每个写接口必须先做组织、班级、绑定关系和对象状态检查，再执行数据库事务；拒绝测试必须覆盖正常请求、改 URL、改请求体和重放请求四种方式。

## 6. 当前原型的诚实说明

当前领域包已提供 `requireRole`、`getSessionUser`、`canAccessClassroom`、`canReadParentSummary` 和 `canAccessSafeguardingCase`，并覆盖稳定拒绝测试；Cookie policy 已要求 HttpOnly、SameSite=Lax、Path=/ 和退出清除。它们尚未接入真实 API/Auth.js 会话或数据库查询层，不能据此宣称生产认证已完成。
