==================================================
一、产品背景与设计目标
==================================================

产品名称：知野
产品口号：让知识在田野生长。

产品类型：服务乡村小学 4–6 年级的 AI 课堂复盘与课后学习支持平台。首发完整演示学科为数学，同时支持语文和英语。

核心价值闭环：
教师课后录音复盘 → AI 生成儿童复习卡与教师课堂报告 → 学生课后复习、拍题答疑、做练习 → 系统汇总全班共性困难 → 教师生成精准补讲 → 家长收到看得懂、无排名的学习陪伴摘要。

用户：
1. 教师：希望省时完成课堂复盘、看见全班真正卡住的知识点，并迅速生成补讲和练习。
2. 学生：放学后可能没有可辅导的成人；需要一个不会直接替他做题、而是一步步陪他思考的伙伴。
3. 家长：需要看到孩子可理解的学习摘要和老师建议，但不希望被排名、分数和复杂术语制造焦虑。
4. 学校管理员/保护负责人：维护班级与处理受保护的学生反馈。此角色不需要做成主视觉页面，但要为其预留安全、专业的后台风格。

设计目标：
- 让教师第一眼就知道“现在最值得做的下一步是什么”。
- 让学生在每次答疑中只面对一个适龄的思考动作，而不是一页复杂的答案。
- 让家长在 30 秒内理解孩子这周学到了什么、可以怎样鼓励。
- 在网络不稳定、普通教学电脑和低端手机上依旧保持简单、可信、清晰。

明确避免：
- 不要做成扶贫宣传海报、乡村风景海报、传统教务系统、医院后台或炫技 AI 聊天机器人。
- 不要复制 Apple 的 Logo、设备框、图标、产品名称或具体界面；只借鉴其克制、内容优先、自然层级和即时反馈的体验原则。
- 不要使用霓虹渐变、厚重玻璃、过多阴影、大面积高饱和绿色、卡通动物或幼儿园式插画。
- 不要使用排名、红绿成绩单、同学比较、“落后”“懒惰”等标签；不要在家长端展示完整聊天记录或具体错题图片。

二、总视觉方向：山野暖白 + 克制的 Apple 式体验
==================================================

气质关键词：温暖、安静、可信、自然、有呼吸感、现代、不过度装饰、适合小学生但不幼稚。

页面背景不是纯白，而是暖白。主色来自松林，强调色来自麦穗。让产品具有“知识在田野生长”的隐约意象，但只通过色彩、留白和极少量抽象纹理表达，不使用山水插画铺满背景。

默认浅色主题颜色变量：
- Color/Canvas = #F7F6F1，整个页面暖白背景。
- Color/Surface = #FFFFFF，实色卡片/弹窗。
- Color/Surface-Glass = rgba(255,255,255,0.72)，仅用于顶部工具栏、右侧轻量信息层、底部抽屉；文字必须保持高对比。
- Color/Text-Primary = #1B2420。
- Color/Text-Secondary = #66706A。
- Color/Text-Tertiary = #8A938D。
- Color/Brand-900 = #173D2E。
- Color/Brand-700 = #285943，主按钮、关键链接、当前导航。
- Color/Brand-100 = #E5F0E9，导航高亮、温和提示背景。
- Color/Grain-700 = #A56D19。
- Color/Grain-500 = #C79035，进度、完成、小范围强调。
- Color/Grain-100 = #F6ECD7。
- Color/Info = #3E6F8B。
- Color/Info-Soft = #E8F1F6。
- Color/Warning = #9A6717。
- Color/Warning-Soft = #F8EFDB。
- Color/Danger = #B64747，仅用于明确错误、删除确认和危险状态；禁止用于学生“需要帮助”入口。
- Color/Danger-Soft = #F9E6E6。
- Color/Border = #E4E5DE。
- Color/Overlay = rgba(27,36,32,0.28)。

深色主题也创建变量，但无需把所有画板复制一遍：
- Color/Canvas = #151B18。
- Color/Surface = #202923。
- Color/Surface-Glass = rgba(32,41,35,0.80)。
- 主文字 = #F2F3EE；次文字 = #B8C0BA；Brand 保持可访问的松绿亮度。

排版：
- 字体优先级：SF Pro Display / SF Pro Text；中文使用 PingFang SC；Windows 降级 Microsoft YaHei。不要把 Inter 作为唯一字体。
- 使用清晰的中文字体层级，不使用过细字重。
- Display/L：36px / 44px / Semibold，用于教师首页问候或大标题。
- Heading/L：28px / 36px / Semibold。
- Heading/M：22px / 30px / Semibold。
- Heading/S：18px / 26px / Semibold。
- Body/L：17px / 26px / Regular，学生关键引导问题。
- Body/M：15px / 22px / Regular，正文。
- Body/S：13px / 20px / Regular，辅助说明。
- Label：12px / 16px / Medium，用于状态和字段标签；不要全大写中文。
- 数字与时间使用等宽数字特性（tabular numerals）以保证录音计时稳定。

布局与尺寸：
- 采用 4px 基准间距系统：4、8、12、16、20、24、32、40、48、64。
- 桌面主画板：1440 × 1024；12 列栅格，左右页边距 32px，列间距 24px。
- 平板可选画板：1024 × 1024。
- 手机主画板：390 × 844；内边距 16px；预留底部安全区。
- 卡片圆角 20px；按钮圆角 14px；输入框 12px；浮层/抽屉顶部圆角 24px；图标按钮为圆形。
- 默认卡片不使用强阴影；仅悬浮工具栏、抽屉、Popover、Modal 使用柔和低透明阴影。
- 使用细分隔线和背景层次区分区域，不要堆叠边框。

图标：
- 使用统一的圆角线性图标（Lucide / SF Symbols 风格），线宽约 1.75–2px。
- 关键导航图标：House、Mic、ChartNoAxesCombined、BookOpen、MessageCircle、UserRound。
- 每个图标必须有文字标签；不要让图标成为唯一含义来源。

动效注释：
- 默认：短、柔和、可打断。点击按钮立即有按下态（scale 0.97），松开恢复。
- 页面和浮层使用 opacity + 少量 translate；不要满屏飞入。
- 底部抽屉从底部出现、原路离开；允许拖拽但有明确关闭按钮。
- 减少动态效果：改为 150–200ms 淡入淡出，不使用滑动、回弹和视差。

三、先创建 Foundations 与可复用组件库
==================================================

请先建立一个 Figma 页面：00 Foundations。

在其中创建并命名颜色变量、文字样式、间距变量、圆角变量、阴影效果样式。变量命名示例：
- Color/Canvas
- Color/Brand/700
- Space/16
- Radius/Card
- Typography/Body-M
- Effect/Floating-Surface

再创建一个页面：01 Components。所有后续页面必须优先使用以下组件实例，而不是重复绘制独立矩形：

1. Button 组件集：
- Variant：Primary / Secondary / Tertiary / Danger / Icon。
- State：Default / Hover / Pressed / Disabled / Loading。
- Size：Large（48px 高）/ Medium（40px 高）/ Small（32px 高）。
- 支持 Leading Icon、Trailing Icon、单图标；所有文本必须是真实中文。

2. Card 组件：
- Variant：Default / Highlight / Interactive / Glass / Warning / Empty。
- State：Default / Hover / Selected / Disabled。
- 可插入标题、正文、状态标签、底部操作区。

3. StatusChip 组件：
- 状态：已发布、待确认、待同步、处理中、需补充、低置信度、已完成、失败、草稿。
- 每个状态同时使用图标、文案、颜色，不能只依赖颜色。

4. Navigation：
- DesktopSidebarItem：Default / Active / Collapsed。
- MobileTabItem：Default / Active / Badge。
- 使用真实标签：首页、课堂、洞察、备课与测验、消息、我的。

5. Form：
- TextInput、TextArea、Select、SegmentedControl、RadioCard、Checkbox、SearchInput、VoiceInput。
- 每个输入需有 Default / Focus / Filled / Error / Disabled 状态。
- Error 状态显示明确中文说明，例如“请把题目下半部分也拍进去”，不是“输入错误”。

6. AI 相关组件：
- AiDraftBadge：AI 草稿 + 信息图标。
- JobStatusCard：待同步、已上传、正在转写、正在整理复习卡、等待教师确认、失败。
- ConfidenceNotice：文案“我可能没看清这道题，请补充题干或重拍”。
- EvidencePopover：标题“为什么这样建议”，显示简短依据，不显示模型术语。

7. 结构组件：
- AppShell、DesktopSidebar、TopContextBar、RightContextRail、MobileTabBar。
- BottomSheet：半屏 / 全屏两个变体，包含拖拽把手、关闭按钮、标题和固定底部操作。
- Modal：确认发布、删除、解除绑定等不可逆操作。
- Toast：成功、失败、已保存、离线队列提示。
- EmptyState：插画只用极简线条/抽象形状，不使用卡通人物。

8. 教育业务组件：
- PendingLessonCard。
- LessonRecapCard。
- InsightHeatmapCard。
- StudentProgressRow（不显示排名）。
- QuestionStepCard。
- CompletedStepsAccordion。
- MistakeBookCard。
- ParentSummarySection。
- SafeFeedbackCategoryCard。

为核心组件添加简短红线注释：最小点击尺寸 44×44px，学生主按钮 48px 高，正文对比度满足 WCAG AA，焦点态清晰可见。

A. TD-01 教师桌面首页（1440 × 1024）
------------------------------------

页面目的：让教师一眼看到最重要的下一步——确认上一节课的复习卡。

整体布局：
- 左侧固定导航 224px，暖白半透明或实色表面。
- 中央主内容自适应。
- 右侧上下文栏 320px；可收起，但此画板展示展开态。

左侧导航：
- 顶部是文字 Logo“知野”，下方小字“课堂里的每一次看见”。不要图形 Logo。
- 菜单：首页（激活）、课堂、洞察、备课与测验、消息。
- 首页使用浅松绿背景胶囊、松绿色图标和深色文字。
- 底部显示设置与退出，使用低强调层级。

中央：
- 顶部上下文行：左侧“李老师，早上好”，右侧班级选择器“五年级（2）班”、学科选择器“数学”、通知图标。
- 主标题：今天，先完成这一节课堂复盘。标题下说明“确认后，学生就能看到适合他们的复习卡。”
- 主视觉 PendingLessonCard：
  - 左上 StatusChip：待确认。
  - 标题“分数的基本性质”。
  - 副信息“今天 10:30 · 40 分钟课堂录音”。
  - 状态时间线：已上传 ✓ → 已转写 ✓ → 复习卡待确认（当前）。
  - 主按钮“查看并确认”；次操作“稍后处理”。
  - 右侧有简洁的抽象课堂笔记/声波图形，不使用真实人物图片。
- 下方“最近课堂”横向小卡 3 张，包含：认识分数、分数的基本性质、约分与通分；明确不要抢主卡注意力。
- 最下方一个弱强调快捷区：“开始录音”“创建练习”“查看所有课堂”。

右侧今日动态：
- 标题“今日动态”。
- 待办卡：3 个待完成任务。
- 新消息卡：2 条新消息，显示学生/家长昵称和不暴露隐私的预览。
- 班级困惑摘要卡：标题“全班最近卡在这里”，两行趋势：单位换算 ↑、约分步骤 ↑，底部文字链接“查看完整热力图”。

C. TD-03 教师课堂复盘编辑（1440 × 1024）
------------------------------------

页面目的：让教师审核 AI 草稿并决定发布给学生的内容。

布局：
- 顶部栏：左“← 返回课堂”，中间“分数的基本性质”，右“已自动保存 · 10:42”。
- 下方 6:4 双栏，间距 24px。
- 左栏标题“学生复习卡”，旁边 AiDraftBadge“AI 草稿”。这是学生将看到的内容，视觉更明亮。
- 左栏内容模块顺序：
  1. 本节学到了什么：一句儿童友好总结。
  2. 关键知识点：3 个小标签/短卡。
  3. 容易弄错的地方：2 条带例子的提醒。
  4. 自检问题：2 个可展开问题。
  5. 课后小练习：3 道题目预览。
- 每个模块右上只有轻量“编辑”图标；页面底部可有“重新生成此部分”。
- 右栏标题“教师课堂报告”，小锁图标 + “仅你可见”。视觉更安静、对比度略低。
- 右栏模块：课堂节奏、互动情况、共性难点与依据、下节课建议。每个建议都应有“依据”链接/Popover。
- 底部固定 ActionBar：左“保存草稿”，右主按钮“确认并发布给学生”。
- 点击发布打开确认 Modal：标题“准备发布给 32 名学生”，正文“学生将看到左侧复习卡内容。你以后仍可更新。”按钮“确认发布”。

E. TD-05 班级洞察热力图（1440 × 1024）
------------------------------------

页面目的：聚合共性困难，绝不把学生变成排名。
- 顶部：标题“班级学习地图”，说明“这不是成绩排名，而是帮助你看见大家在哪一步需要再讲一讲。”
- 筛选控件：班级、学科、时间范围、章节。
- 主图为大面积热力图，不展示个人姓名；支持 Hover tooltip：例如“约分 · 计算步骤：14 名学生在答疑或练习中卡在此处”。
- 右侧“本周建议”：补讲建议、可生成的三道练习、可查看的匿名学习事实摘要。
- 下方“需要留意的变化”：只描述趋势，如“单位换算的求助次数比上周多 6 次”，不出现负面人格评价。

F. TD-06 教师备课助手（1440 × 1024）
------------------------------------

- 左栏是输入与范围控制：教材版本、章节、课时目标、班级基础、是否参考最近热力图（默认勾选）。

==================================================
五、必须生成的系统状态与边界状态
==================================================

在“05 States & Prototype”页面中，系统化展示以下状态，不要只用一行文字：

1. AI 处理状态：
- 待同步：云朵/离线图标 + “将在联网后发送”。
- 已上传：已安全保存。
- 正在转写：正在把课堂内容整理成文字。
- 正在整理复习卡：正在把这节课变成孩子看得懂的复习卡。
- 等待教师确认：复习卡准备好了，等你看一眼。
- 需补充：题图不完整/音频过短。
- 低置信度：我可能没有听清或看清。
- 失败：没有完成，但草稿还在；提供重试。

2. 网络与离线：
- 顶部窄提示条，不遮挡主要内容。
- 离线时保存草稿，明确“尚未发送”。
- 恢复网络后显示“已同步”，并提供可关闭的 Toast。

3. 空态：
- 教师无课堂：开始第一节课堂。
- 教师无班级洞察：学生完成一次复习或答疑后，这里会慢慢长出班级的学习地图。
- 学生无错题：每一次认真想过的题，都值得被记住。
- 家长暂无摘要：老师发布后，你会在这里看到本周学习陪伴。

4. 错误与确认：
- 上传失败、权限不足、消息发送失败、删除录音、确认发布、解除监护绑定。
- 每个错误必须给可执行的下一步，而非只有“发生错误”。

==================================================
六、原型连线与微交互
==================================================

请至少建立以下可点击原型：

1. 教师：TD-01 点击“查看并确认” → TD-03；TD-03 点击“确认并发布给学生” → 发布确认 Modal → 成功 Toast；TD-01 点击“查看完整热力图” → TD-05；TD-02 点击“生成补讲建议” → TD-06。
2. 教师：TD-04 点击“结束并生成复盘” → 处理状态 → TD-03。
3. 学生：SM-01 点击“拍照答疑” → SM-02；选择“我卡在某一步” → SM-03；点击“再提示一点”展示下一层提示；点击“我想到了”进入下一步骤；完成后 → SM-05；点击“查看错题本” → SM-06。
4. 学生：SM-02 题图不清 → SM-04 → 点击“重新拍照”返回 SM-02。
5. 学生：SM-01 或消息入口点击“想说一说” → SM-07；点击“我有点害怕，需要帮助” → SM-08 → 提交成功状态。
6. 家长：GM-01 点击“联系老师” → GM-02。

动效标注：
- Button Pressed：0.97 缩放，立即反馈。
- BottomSheet：从底部进入，约 280–360ms，轻微但不明显的弹簧；可向下拖拽关闭。
- Modal：背景轻微变暗，Modal 从触发点附近淡入并小幅放大。
- 页面切换：短淡入/轻微平移；不做整页大幅滑动。
- `Reduced Motion` 变体：移除滑动与弹簧，只保留 150–200ms 透明度变化。

==================================================
七、无障碍与实现标注
==================================================

- 正文文字与背景至少 WCAG AA 4.5:1 对比度；大字至少 3:1。
- 不使用颜色作为唯一状态：所有状态同时有图标、中文文本与颜色。
- 所有交互目标最小 44×44px；学生主按钮至少 48px 高。
- 每个图标按钮要有可见或可访问的中文标签。
- 图表、波形、题图必须有文本等价说明。
- 键盘焦点状态使用清晰的松绿外描边；Modal/BottomSheet 打开时焦点留在内部，关闭后回到触发按钮。
- 在画板旁以注释写明：手机端所有核心操作不依赖拖拽；离线时不清除输入；AI 输出始终标注“AI 草稿/AI 建议”。

==================================================
八、生成质量与命名要求
==================================================

- 所有画板、图层、组件使用清楚中文/英文混合命名，例如 `TD-01 Dashboard / Pending Lesson`、`SM-03 Question Flow / Step 2`。
- 使用 Auto Layout、组件变体、颜色/文字/间距变量，而不是大量绝对定位的独立图层。
- 所有重复卡片、状态标签、按钮和导航必须复用组件实例。
- 使用真实中文内容；绝不使用 Lorem Ipsum、英文占位符或“Title/Subtitle/Button”。
- 如果使用抽象装饰，只允许在教师首页主卡的一角添加低对比度声波/纸张纹理；不要影响阅读。
- 确保 390px 手机画板底部导航、固定操作栏和安全区不遮挡内容；桌面画板的右栏在窄屏可收起。
- 输出应是高保真可展示的产品设计，而不是线框图；同时保持足够留白和可实现性。
