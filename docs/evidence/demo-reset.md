# Demo reset · 演示数据复位

## 入口

教师端：`设置` → `演示数据` → `重置演示数据` → 二次确认。

该入口调用 `PrototypeContext.resetPrototype()`，恢复本地原型数据，便于重复演示课堂录音、复盘审核和学生回流链路。

## 使用边界

- 这是本地原型演示数据复位，不是生产数据删除工具。
- 复位前应保存本次演示需要的截图、录屏和复盘草稿。
- 真实录音文件由浏览器和本地 AI 服务按临时文件路径处理；本日验收不把复位动作描述为云端数据清理。

## 演示前检查

1. 复位演示数据。
2. 重新加载教师端，确认课堂、洞察、学生任务回到默认验收夹具。
3. 只在需要时打开麦克风权限，并确认本地 AI `/health` 可用。
